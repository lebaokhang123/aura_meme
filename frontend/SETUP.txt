AURAMEME — STITCH REACT + AUTH API

Frontend chính là thư mục frontend/ của checkout Auth đang review.
Nguồn đã được Owner nghiệm thu sơ bộ: docs/plan/master/stitch-react-preview.
Giữ 14 màn Stitch và các nguồn tham chiếu; header/footer đã dùng chung theo Owner 2026-11-12.
Giữ UI Stitch; tái sử dụng Auth backend hiện có, chưa nối Social hoặc Game Mechanics.

CHẠY TRÊN WINDOWS:
1. Cần Node.js >=22.12.0 và npm.
2. Mở terminal tại checkout Auth: cd frontend
3. npm ci
4. npm run dev
5. Truy cập http://localhost:5173; cổng 5173 cố định. Backend chạy tại 127.0.0.1:8000.
   Vite proxy /api giữ Origin; backend development phải cho phép http://localhost:5173.

BUILD / KIỂM THỬ:
npm run build
npm run preview -- --port 5173 (cần backend và allowed origin localhost:5173)
node --test tests/*test.mjs
npm test (build mock; Chrome đã cài, 149 regression demo, không backend/DB).
Sau npm run build: npx playwright test --config=../.github/playwright.auth.config.mjs
(8 Auth UI tests với HTTP stub; Chromium đi kèm Playwright).
Auth E2E thật: từ backend chạy python tests/run_auth_browser.py [đường-dẫn-e2e.local/.env].
Runner chỉ nhận aurameme_e2e/role aurameme_e2e_app rỗng, guard schema/revision;
không migrate/reset; dọn đúng user/session/role tổng hợp do test tạo và kiểm 28 bảng rỗng.
Cần build API mode và cài Chromium trước; DB development/demo không được sử dụng.

run.bat demo/dev khởi động backend + frontend Auth API thật, có guard DB hiện có.
Launcher cần .venv và demo.local của chính checkout; worktree mới không tự nhận secrets.
Để review worktree với demo.local bên ngoài, chạy từ backend bằng Python đã cài dependencies:
python -c "from pathlib import Path; from app.demo import activate_demo; import uvicorn; activate_demo(Path(r'C:\path\to\demo.local')); uvicorn.run('app.main:app',host='127.0.0.1',port=8000)"
Sau đó chạy npm run dev từ frontend của cùng worktree. Không dùng -I với venv checkout khác,
vì editable install có thể import sai source. Không sao chép secrets vào Git.
Không chạy migration/seed trên development/demo để thử đăng nhập.

AUTH LOCAL:
API mode là mặc định của npm run dev/build và run.bat demo/dev. Cookie HttpOnly + CSRF;
danh tính/quyền lấy từ /api/v1/users/me. localStorage demo cũ không có quyền đăng nhập.
Đăng ký thường chỉ USER, mật khẩu 12–128 ký tự; đăng ký xong chuyển về đăng nhập.
Ba tài khoản demo dùng mật khẩu đã nhập riêng: khang_dev@example.com, kien_dev@example.com
(USER + ADMIN), gigachad@example.com (USER). Không có mật khẩu trong source.
