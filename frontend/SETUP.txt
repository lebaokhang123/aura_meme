CHẠY TRÊN WINDOWS:
1. Cần Node.js >=22.12.0 và npm.
2. Mở terminal: cd D:\Big\du_an_lon\aura_meme\frontend
3. npm ci
4. npm run dev
5. Truy cập http://127.0.0.1:5173 (xem cổng thực tế trong terminal nếu bị chiếm).

BUILD / KIỂM THỬ:
npm run build
npm run preview -- --port 4173
node --test tests/*test.mjs
npm test (Chrome đã cài; bộ test chỉ khởi động Vite preview, không backend/DB).

Không dùng run.bat ở root cho frontend demo này: launcher cũ có khởi động backend/kiểm DB.

GIỚI HẠN QUAN TRỌNG:
- Bố cục được sinh từ chính DOM của 14 bản Stitch, không vẽ lại bằng UI cũ.
- CSS utility dùng Tailwind Play CDN vì đó chính là cách HTML gốc hoạt động.
  Cần Internet để tải Tailwind, Google Fonts và nhiều ảnh googleusercontent trong Stitch.
  Không phải frontend production offline-ready.
- Những hiệu ứng script gốc được nạp theo vị trí của script trong HTML nguồn.
- Khung so sánh /reference/*.png và nguyên bản /stitch-original/*/code.html.
- Dữ liệu demo không thể dùng thay xác thực, DB, catalog, quyền asset thật.
- Ảnh/GIF tạo bài chỉ được lưu cục bộ trong IndexedDB, không upload server; chưa có mở hòm trả thưởng.
- Bản promotion ban đầu trùng byte với preview; bản stabilization tiếp theo
  sửa ảnh local và responsive dưới768px. Khung ảnh desktop được giữ theo số đo trước sửa;
  bản chỉnh 2026-11-12 tiếp tục chuẩn hóa shell, Home/Auth và bảo trì theo nhận xét Owner.
- Logo lỗi đã thay bằng favicon64 local; ảnh bảo trì hiện dùng baotri.png Owner cung cấp.
  Tailwind/Google Fonts/các ảnh khác vẫn cần Internet; đề xuất self-host trong HANDOFF.
- Chỉ có 8 route ở trên và trang policy trắng. Thông tin là hộp tên/avatar demo;
  OAuth, thông báo và các nút tính năng tương lai vẫn là placeholder;
  các route/API chức năng của frontend cũ chỉ còn trong bản sao lưu.
