Text fonts are the original variable TTFs from the respective `google/fonts` source directories; icons were retrieved from `fonts.googleapis.com/css2?family=Material+Symbols+Outlined&icon_names=...`. These files are self-hosted so the UI does not require third-party asset requests. Font licenses do not license unrelated prototype artwork or imply a project-wide MIT license.
